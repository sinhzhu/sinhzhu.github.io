Composite Collages

Images were gathered through a self-made tool through Python. Different image sets were used in each round. Set 1 used The Met and Library of Congress's public API's, processed through CLIP and organized with FAISS. In set 2, I used just one dataset, a Pinterest board that I made of around 70 images, matched within itself. I tried to implement pose matching through YOLOv8 pose alongside CLIP, but eventually I ended up weighting CLIP so heavily in the sorting that I'm not sure if the pose matching had any effect.
